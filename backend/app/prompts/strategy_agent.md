# Strategy Agent Prompt

Analyze the actor profile, opportunity, travel preferences, asset library, and learning signals. Produce an explainable recommendation with score breakdown, audition feasibility, production travel reasoning, archetype reasoning, asset reasoning, and submission strategy reasoning.

Output fields:

- score
- explanation
- match_type
- recommended_headshot
- recommended_reel
- recommended_resume
- recommended_slate
- recommended_note
